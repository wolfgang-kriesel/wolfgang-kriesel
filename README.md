### How I build

- **Grounded, not hand-wavy** — decisions rest on verified computation and retrieved
  sources with citations, not on an LLM's opinion.
- **LLM-agnostic** — a thin provider layer defaults to a deterministic mock; Claude /
  GPT / Grok drop in via one environment variable.
- **Engineering hygiene** — MIT-licensed, tests for the core logic, honest limitations,
  clean commit histories, and a one-command demo per repo.
